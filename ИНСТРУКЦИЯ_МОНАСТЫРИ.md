# Импорт списков монастырей

Бот хранит три категории:

| Категория | Кто | Откуда |
|---|---|---|
| Насельники | монашествующие мужских монастырей (от архиерея до послушника) | списки «… мм спис 25» |
| Насельницы | монашествующие женских монастырей (от игумении до послушницы) | списки «… жм спис 25» |
| Духовенство при монастырях | белое духовенство, у которого в «месте служения» указан монастырь | уже есть в базе, привязывается автоматически |

В боте: кнопка **🏛 Монастыри** → категория → монастырь (или «Все»).
Поиск находит и по монашескому имени («Серафим»), и по мирской фамилии.
«📋 Список» показывает только белое духовенство, как и раньше.

## Запуск

```bash
python3 import_monasteries.py "путь/к/папке со списками" --dry-run   # проверка, без записи
python3 import_monasteries.py "путь/к/папке со списками"             # импорт
```

Скрипт выводит по каждому файлу: монастырь, сколько добавлено/обновлено,
предупреждения; затем — кого из белого духовенства привязал к монастырям и
чьё место служения распознать не удалось.

Повторный запуск (например, со списками за следующий год) безопасен:
человек с теми же ФИО и годом рождения обновляется, а не дублируется.

## Форматы файлов

- **.docx** — читается везде.
- **.rtf** и **старый .doc (Word 97–2003)** — только на Mac (через встроенный `textutil`).
  На сервере их нужно пересохранить в Word как .docx, либо импортировать
  на Mac и скопировать готовую `database.db` на сервер вручную, при
  остановленном боте (`deploy.sh` базу на сервере не трогает).
- Формат определяется по содержимому: .docx, сохранённый с расширением .doc, читается как .docx.
- Если скрипт пишет «таблица не распознана» — откройте файл в Word и
  «Сохранить как → Документ Word (.docx)». Так нужно сделать для
  `37_СКЕИ мм спис 25` и `38_СН мм спис 25`.

## Особенности данных

- В списках указаны **только годы** рождения и рукоположения, поэтому
  насельники не попадают в «🎉 Именинники» (там нужны полные даты) —
  кроме архиереев, для которых даты загружаются отдельно (см. ниже).
- Архиереи в списках — наместники. Наместник нескольких обителей
  (архиепископ Виктор — Свято-Успенский и Свято-Ильинский) показывается
  в каждой из них; запись о человеке при этом одна.
- Список монастыря — источник истины: кого нет в новом списке, тот
  выбывает из этого монастыря (запись о человеке остаётся).

## Даты архиереев-викариев

Дни ангела, постриг и хиротонии (в диакона, иерея, епископа) пяти
архиереев перенесены из «даты поздравлений викарии.pdf» в
`data/vicar_dates.csv`. После импорта списков монастырей:

```bash
python3 import_vicar_dates.py
```

После этого архиереи попадают в «🎉 Именинники»: по тезоименитству — в
день ангела, по хиротонии — в день пострига и каждой из трёх хиротоний
(с подсчётом лет и юбилеев). Повторный импорт списков монастырей эти даты
не стирает. При изменениях дат правьте CSV и запускайте скрипт снова.
- Подворья и скиты (например, «скит Св.-Арх.-Мих.») автоматически не
  привязываются — скрипт выводит их в списке «Монастырь не найден».
